## 📌 Project Overview

This project provides actionable business insights by transforming raw transactional data into meaningful interactive visualizations. It helps business stakeholders track total revenue, analyze product-level sales, monitor order delivery lifecycles, and evaluate marketing channel effectiveness.

---

## 🔑 Key Insights & Features

* **Revenue Overview:** Achieved **$1.26M** in total earnings, with top-performing categories being **Laptops**, **Chairs**, and **Printers**.
* **Order Tracking:** Analyzed **4K total units sold** across various order statuses (*Delivered, Shipped, Pending, Returned, Cancelled*).
* **Marketing Channels:** Highlighted **Instagram** and **Google** as the primary referral channels driving maximum order volume.
* **Payment Methods Analysis:** Categorized customer preference across *Cash, Credit Card, Debit Card, and Gift Cards*.

---

## 🛠️ Tools & Technologies Used

* **Business Intelligence:** Microsoft Power BI
* **Data Transformation:** Power Query (ETL)
* **Data Modeling & Calculations:** DAX (Data Analysis Expressions)
* **Visuals & UX Design:** Custom Theme Formatting, Rounded Containers, Interactive Dropdown & Tile Slicers, KPI Cards
